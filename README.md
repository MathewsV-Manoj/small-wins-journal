# Small Wins Journal

> A place to keep the wins that are easy to overlook but still worth remembering.

## How to use it

- Write down one thing that went a little better today.
- Include effort, not only finished results.
- Read back through old entries when you need a reminder.

## A small note to yourself

Small wins add up, even when the day did not look spectacular.
